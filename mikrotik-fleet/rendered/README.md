# rendered/

Generated by `./render.py` from `templates/router.rsc.j2` + `sites.yaml`.
Committed on purpose — this is what a router actually eats, so PR review
reads *this* diff, not just the `sites.yaml` diff (docs/PLAN.md section 2).

Contains only placeholder secret tokens (`{{SECRET:category:site}}`), never
real secret values — see `deploy.py` and docs/secrets-setup.md for pass 2.

Do not hand-edit files in this directory. Edit `sites.yaml` or
`templates/router.rsc.j2` and re-run `./render.py`. CI runs `./render.py
--check` on every PR to catch a stale render before it lands.
